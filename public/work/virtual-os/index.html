01 / The project

A personal reason to build something different.

A digital anniversary gift presented as a small operating system in the browser. Instead of moving through a single page, the recipient explores a desktop and opens individual apps. The project sits in my Gifts collection.

02 / Interaction design

The desktop is the navigation.

The React desktop manages open windows, their stacking order, minimising, restoring, and closing. A taskbar and Start Menu connect those actions. Gallery, music, memory match, a timeline, quiz, and achievements share the same desktop shell.

03 / Implementation

Small apps inside a shared interface.

Reusable components separate window frames, desktop icons, the taskbar, and menus from the individual apps. React context provides shared sound settings and achievements. The project uses Vite and includes react-draggable for window interaction.

04 / Portfolio focus

The details between opening and closing.

This project adds a more playful side to my frontend work: coordinating interaction states and making several small experiences feel connected. The illustration here uses neutral content; personal photographs and messages are not reproduced.
