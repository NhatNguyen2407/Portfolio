01 / The project

A story that unfolds one interaction at a time.

A six-month anniversary gift built as a small interactive website. It begins with an envelope and opens into a menu of chapters, combining written messages, photographs, and music. It is a personal frontend project in my Gifts collection.

02 / Interaction design

Choose a chapter. Return to the story.

The page uses a chapter menu and back-to-menu controls to move between sections. An opening sequence introduces the experience before the main content, giving the site a clear beginning rather than showing every section at once.

03 / Implementation

Direct browser interactions.

HTML defines the sections, CSS provides their visual presentation, and JavaScript switches the active section through data-target navigation. Audio controls track the current song and pause the previous track when another starts; navigation also stops playback.

04 / Portfolio focus

A compact counterpart to Virtual OS.

This project shows a simpler approach to interactive storytelling with browser APIs and DOM events. Together, the two Gifts projects show different ways of structuring a personal experience. Private messages and photographs are omitted from this portfolio overview.
