# Portfolio fonts

Kajiro: supplied by the owner in kajiro.rar, converted losslessly from TTF to WOFF and self-hosted as public/assets/kajiro.woff. Applied to the requested display headings using data-type-role="display", with responsive sizes adjusted for its condensed proportions. The archive contained no license document; keep the owner’s applicable webfont license with deployment records and review redistribution before a public GitHub export.

Advercase: the supplied Demo license permits personal testing but prohibits promotional/commercial use and redistribution in public or shared environments. The demo binaries are not bundled or hosted. Manrope remains the body font pending a permitted webfont version.

Downloaded CV, resume and project-portfolio documents have not been edited.
